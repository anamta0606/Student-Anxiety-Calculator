# Student Anxiety Calculator

## Overview
The Student Anxiety Calculator is an academic C++ project developed to help estimate students' anxiety levels based on selected inputs. The project demonstrates the use of Object-Oriented Programming (OOP) concepts.

## Features
- User-friendly console application
- Anxiety level calculation
- Object-Oriented Programming concepts
- Simple and structured code

## Technologies Used
- C++
- Object-Oriented Programming (OOP)
